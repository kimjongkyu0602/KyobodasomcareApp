# App Store 심사 점검표 (하이브리드 앱 껍데기)

- 대상: 교보다솜케어 헬스케어서비스 iOS 앱 (`com.kyobodasomcare.app`, 1.0.0 / 빌드 2)
- 점검일: 2026-11-11 (한국 시간)
- 기준: App Store Review Guidelines + 하이브리드(WebView) 앱 반려 사례
- 상태 구분: **완료** (원래 문제 없음) · **앱에서 보완함** (이번에 수정) · **웹팀 필요** · **사용자 필요** (App Store Connect 입력·계정 제공 등)

## 남은 반려 위험

1. **회원탈퇴·개인정보처리방침 URL** — 없으면 거의 반드시 반려 (5.1.1). 웹팀 작업 1순위.
2. **테스트 계정 / 본인인증** — 심사자가 로그인하지 못하면 2.1 반려. 본인인증 없이 들어갈 수 있는 심사용 계정 권장.
3. **4.2 최소 기능** — 웹사이트를 감싼 앱으로 보일 수 있음. 심사 메모에 앱 기능(푸시, 생체인증, 탭, 오프라인 화면 등) 설명. 반려되면 푸시 알림함 같은 앱 전용 기능 추가 검토.
4. **간편인증 실제 완료 흐름** — 팝업이 열리는 구조는 수정했지만, 실제 인증 → 로그인 완료까지 테스트 계정으로 아이폰에서 한 번 확인 필요.
